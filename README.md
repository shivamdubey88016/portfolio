# Developer Universe Portfolio

Interactive personal portfolio built with React + Vite, featuring:

- React Three Fiber 3D universe background
- Framer Motion animations and scroll transitions
- Tailwind CSS glassmorphism interface
- Responsive sections for About, Skills, Projects, Timeline, Contact
- Dark/Light mode toggle, typing hero effect, glowing cursor

## Tech Stack

- React.js (functional components + hooks)
- Vite
- Tailwind CSS
- Framer Motion
- React Three Fiber + Drei

## Run Locally

```bash
npm install
npm run dev
```

Open the shown local URL in your browser.

## Production Build

```bash
npm run build
npm run preview
```

## Personalization

- Update your details in `src/data/portfolioData.js`
- Replace `public/Shivam_Dubey_Resume.pdf` with your resume file
- Set real social/project links in the data file (currently placeholders)

## Deploy (Vercel)

1. Push this project to GitHub.
2. Import repository in Vercel.
3. Use default settings:
   - Build command: `npm run build`
   - Output directory: `dist`
